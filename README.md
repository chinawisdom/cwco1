# 项目管理认证培训开源工具归档库

本仓库用于归档与项目管理、PMP、Scrum、敏捷培训相关的开源工具与学习资源，方便后续评估、部署和使用。

## 已归档项目
- [OpenOLAT - 开源学习管理系统](./README-OPENOLAT.md)
  - 适用于搭建私有化PMP/项目管理培训平台
  - 支持课程管理、在线考试、证书颁发等完整功能
  - 开源协议：Apache 2.0 License

## 仓库用途
- 集中管理项目管理培训相关的开源工具
- 为企业/机构私有化部署提供参考与归档
- 记录每个工具的适配场景、部署方案与使用建议
