## 2. 核心功能清单
### 课程管理
模块化课程搭建，支持SCORM标准，兼容视频、文档等各类多媒体内容，支持课程分类检索。

### 评估测试
支持QTI试题标准，内置题库、在线答题、自动评分、问卷调研与数据统计能力。

### 认证管理
课程完成后自动颁发证书，可追踪学习进度、培训时长与认证有效期。

### 沟通协作
内置讨论区、即时消息、消息通知、小组协作功能。

### 系统管理
精细化角色权限、组织架构管理，完整数据报表，支持自定义系统配置。

### 技术特性
支持二次开发与系统集成，界面主题可定制，多语言适配，支持集群扩展部署。

## 3. 与PMP/项目管理培训适配
### PMP认证培训
1. 可按PMBOK知识体系拆分模块化课程，规划完整备考学习路径
2. 搭建题库，实现随机组卷、模拟考试
3. 实时追踪学员学习进度与知识掌握情况
4. 满足PMI 35小时培训学时记录，自动出具培训证书
5. 支持持证人员继续教育与PDU积分管理

### Scrum/敏捷培训
1. 支持团队沙盘、角色扮演等实战演练场景
2. 借助小组协作功能开展团队训练
3. 全流程管理CSM、PSM等认证培训进度

### 企业内训优势
开源免费、私有部署保障数据安全，功能可按需定制，支持大规模并发使用。

## 4. 部署和使用建议
### 硬件要求
CPU 4核及以上、内存8GB及以上、存储空间100GB以上。

### 运行环境
- Java 17 JDK
- PostgreSQL 9.4+ / MySQL 8.0+
- Tomcat 10.0/10.1
- Maven 3.8+

### 部署步骤
1. 新建数据库与账号，执行项目内置数据表脚本
2. 复制配置模板文件，填写数据库、文件存储、邮件等参数
3. 使用Maven编译打包，将war包部署至Tomcat
4. 启动服务，默认地址：http://your-server:8080/olat
5. 默认账号：administrator / openolat

### 培训平台课程结构参考
```
PMP认证培训
├── 项目管理十大知识领域分模块课程
├── 章节练习
├── 综合模拟考试
└── 证书管理
```

### 角色划分
系统管理员、培训管理员、讲师、学员
